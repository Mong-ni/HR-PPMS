# Documentation language

Write explanatory prose in Markdown documents as an English line followed immediately by its Korean translation; split long passages into sentence-sized pairs. Use Markdown hard line breaks so each pair also appears on separate lines when rendered.  
Markdown 문서의 설명은 영어 한 줄 바로 아래에 한글 번역 한 줄을 작성하고, 긴 내용은 문장 단위로 나눕니다. 렌더링된 화면에서도 두 줄로 표시되도록 Markdown 강제 줄바꿈을 사용합니다.

Technical terms, commands, identifiers, file paths, URLs, and short labels may remain in English. Preserve exact brand names and slogans.  
기술 용어, 명령어, 식별자, 파일 경로, URL, 짧은 레이블은 영어 그대로 사용할 수 있습니다. 브랜드 명칭과 슬로건의 원문을 유지합니다.

This convention applies to documentation prose, including recorded generation prompts; it does not request bilingual text inside logos or UI labels. Preserve original English prompt wording when adding translations.  
이 규칙은 기록된 생성 프롬프트를 포함한 문서 설명에 적용되며, 로고나 UI 레이블에 한영 병기를 추가하라는 뜻은 아닙니다. 번역을 추가할 때 기존 영어 프롬프트 원문을 보존합니다.
