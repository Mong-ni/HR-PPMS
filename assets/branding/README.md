# HR-PPMS branding

[hr-ppms-logo.png](hr-ppms-logo.png) is the current HR-PPMS logo proposal under review, not a finalized design.  
[hr-ppms-logo.png](hr-ppms-logo.png)는 현재 검토 중인 HR-PPMS 로고 시안이며, 확정된 디자인이 아닙니다.

The design retains the first concept's P-shaped symbol, teal check, and horizontal HR-PPMS wordmark, with the Hyundai Rotem wordmark centered above between thin gray rules.  
첫 시안의 P자 심볼, 청록색 체크, 가로형 HR-PPMS 워드마크를 유지하고, 현대로템 워드마크를 얇은 회색 구분선과 함께 상단 중앙에 배치했습니다.

The proposal was edited with the built-in image generation tool using the first concept and the HR-PACE-inspired corporate header as references.  
첫 시안과 HR-PACE 구성을 참고한 기업 로고 헤더를 기준으로 내장 이미지 생성 도구에서 편집했습니다.

The original Hyundai Rotem wordmark is preserved in [hyundai-rotem-official.svg](hyundai-rotem-official.svg), sourced from the [official CI page](https://www.hyundai-rotem.co.kr/ko/company/ci/content.do).  
현대로템 워드마크 원본은 [공식 CI 페이지](https://www.hyundai-rotem.co.kr/ko/company/ci/content.do)에서 가져온 [hyundai-rotem-official.svg](hyundai-rotem-official.svg)로 보관합니다.
